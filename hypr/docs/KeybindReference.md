# Keybinding Reference

## Modifier Keys

| Key | Symbol |
|-----|--------|
| `$mainMod` | SUPER (Windows key) |
| CTRL | Control |
| SHIFT | Shift |
| ALT | Alt |

## Application Launchers

| Binding | Action |
|---------|--------|
| `SUPER + D` | App launcher (rofi drun) |
| `SUPER + Return` | Terminal (kitty) |
| `SUPER + E` | File manager (thunar) |
| `SUPER + B` | Default browser |
| `SUPER + A` | Desktop overview |
| `SUPER + SHIFT + Return` | Drop-down terminal |

## Window Management

| Binding | Action |
|---------|--------|
| `SUPER + Q` | Close window |
| `SUPER + SHIFT + Q` | Kill process |
| `SUPER + F` | Toggle fullscreen |
| `SUPER + CTRL + F` | Maximize |
| `SUPER + SPACE` | Toggle float |
| `SUPER + ALT + SPACE` | Float all |
| `SUPER + O` | Toggle opacity |
| `SUPER + G` | Toggle group |
| `SUPER + Tab` | Next in group |
| `SUPER + SHIFT + Tab` | Previous in group |

## Resize / Move / Swap

| Binding | Action |
|---------|--------|
| `SUPER + SHIFT + Arrows` | Resize window |
| `SUPER + CTRL + Arrows` | Move window |
| `SUPER + ALT + Arrows` | Swap windows |
| `SUPER + Arrows` | Focus direction |

## Workspaces

| Binding | Action |
|---------|--------|
| `SUPER + [1-9,0]` | Switch to workspace |
| `SUPER + SHIFT + [1-9,0]` | Move window to workspace |
| `SUPER + CTRL + [1-9,0]` | Move window silently |
| `SUPER + Tab` | Next workspace |
| `SUPER + SHIFT + Tab` | Previous workspace |
| `SUPER + U` | Toggle special workspace |
| `SUPER + SHIFT + U` | Move to special workspace |
| `SUPER + CTRL + F9-F12` | Move workspace to monitor |

## Layout

| Binding | Action |
|---------|--------|
| `SUPER + I` | Add master |
| `SUPER + CTRL + D` | Remove master |
| `SUPER + CTRL + Return` | Swap with master |
| `SUPER + SHIFT + I` | Toggle split (dwindle) |
| `SUPER + P` | Toggle pseudo |
| `SUPER + M` | Set split ratio 0.3 |
