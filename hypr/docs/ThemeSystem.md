# Theme System

## Color Generation

Colors are generated by **wallust** from the current wallpaper.

```
Wallpaper → wallust → wallust-hyprland.conf → appearance/colors.conf → decoration.conf
```

### Color Variables

| Variable | Usage |
|----------|-------|
| `$color0` - `$color15` | Terminal/palette colors |
| `$background` | Background color |
| `$foreground` | Foreground color |
| `$color10` | Inactive border, inactive shadow |
| `$color12` | Active border, active shadow |
| `$color13` | Hyprlock text |
| `$color15` | Group border active |

### Where Colors Are Used

- **Borders**: `appearance/decoration.conf` → `col.active_border`, `col.inactive_border`
- **Shadow**: `appearance/decoration.conf` → `shadow.color`, `shadow.color_inactive`
- **Groups**: `appearance/decoration.conf` → `group.col.border_active`, `groupbar.col.active`
- **Lock screen**: `hyprlock.conf` → label colors, input field colors

## Changing Theme

1. Change wallpaper: `SUPER + W`
2. Wallust regenerates colors automatically
3. Hyprland reloads the color config

Or use the theme switcher: `SUPER + T`

## Animation Style

Current: **Minimal-2** (quart ease-out)

```conf
bezier = quart, 0.25, 1, 0.5, 1
animation = windows, 1, 6, quart, slide
animation = border, 1, 6, quart
animation = borderangle, 1, 6, quart
animation = fade, 1, 6, quart
animation = workspaces, 1, 6, quart
```

To change: edit `appearance/animations.conf` or use `SUPER + SHIFT + A` (animations menu).

## Cursor

Theme: **Bibata-Modern-Ice** via hyprcursor

```conf
env = HYPRCURSOR_THEME,Bibata-Modern-Ice
env = HYPRCURSOR_SIZE,24
```

Change in `core/environment.conf`.
